# Form Chat

Projeto de formulários em formato de conversa/chat, desenvolvido para proporcionar uma experiência mais dinâmica e interativa ao usuário.

## 🚀 Tecnologias Utilizadas

- TypeScript
- Next.js
- React
- Tailwind CSS

## ✨ Funcionalidades

- Formulários em estilo de chat
- Interface moderna
- Navegação dinâmica
- Validação de respostas
- Experiência interativa
- Layout responsivo

## 🎯 Objetivo

Melhorar a experiência do usuário em formulários tradicionais, tornando o preenchimento mais natural e intuitivo.
